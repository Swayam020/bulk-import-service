# Notes

**What this file is for.** Every time you hit something you didn't expect, write it here in
your own words — the bug, why it happened, and what you changed. Do not write "fixed the
transaction issue." Write what the transaction was doing and why that was wrong.

This is the file you re-read before an interview. The README says what the project does;
this says what you learned building it, which is the thing they actually ask about.

One entry per milestone, minimum. Date them.
